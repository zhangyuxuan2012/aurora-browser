# 极光快导 - Chrome 扩展

> 把极光浏览器的核心功能变成一个 Chrome 扩展，可安装到 Chrome / Edge / 360 / Brave 等 Chromium 内核浏览器。

## ✨ 核心功能

### 1. 🛡️ 智能防弹窗
- 自动拦截广告弹窗、空白弹窗、图片直链弹窗
- 拦截常见广告域名（popads、popcash、doubleclick 等）
- 拦截可疑自动跳转
- 实时拦截计数，扩展图标显示拦截数量
- 可随时开关

### 2. 📑 201 站导航（分屏模式）
- **左屏正常浏览，右屏网站导航**
- 点击导航网站，在左屏打开
- 支持左屏刷新、后退、前进控制
- 11 个分类：常用、视频、社交、购物、开发、设计、办公、新闻、学习、生活、工具
- 搜索框支持网站搜索和网址直达

### 3. 🔍 弹出菜单
- 点击扩展图标弹出功能菜单
- 网站导航（4列网格布局）
- 防弹窗开关
- 一键清除浏览数据
- 打开无痕窗口
- 打开完整极光导航

### 4. 🧹 隐私保护
- 一键清除缓存、Cookie、历史、下载记录、表单数据、密码、IndexedDB、localStorage、Service Worker
- 打开无痕窗口
- 不收集任何用户数据，所有处理本地完成

### 5. 🖱️ 右键菜单
- 打开极光快导（分屏）
- 打开完整极光导航
- 切换防弹窗
- 清除浏览数据

## 📦 安装方法

### 方法一：加载已解压的扩展（推荐，立刻能用）

1. 下载本扩展文件夹（`aurora-extension`）
2. 打开 Chrome / Edge，地址栏输入：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `aurora-extension` 文件夹
6. 安装完成！扩展图标会出现在浏览器工具栏

### 方法二：打包成 .crx 离线安装

1. 在扩展管理页面点击「打包扩展程序」
2. 选择 `aurora-extension` 文件夹
3. 生成 `.crx` 文件
4. 把 `.crx` 文件拖到扩展管理页面安装

## 🎮 使用说明

### 分屏导航（核心功能）

1. 安装扩展后，右键任意页面 → 「🌌 打开极光快导（分屏）」
2. 或者点击扩展图标 → 「全导航」按钮
3. 浏览器右侧会出现侧边栏，显示网站导航
4. 点击导航中的网站，会在**左侧当前标签页**打开
5. 底部按钮可以控制左屏：刷新、后退、前进
6. 左屏正常浏览，右屏随时切换网站，效率翻倍

### 防弹窗

- 默认开启，自动拦截广告弹窗
- 拦截时页面右上角会显示提示
- 扩展图标徽章显示累计拦截数量
- 可在弹出菜单或右键菜单中关闭

### 弹出菜单

- 点击扩展图标打开
- 顶部搜索框：搜索网站或输入网址直达
- 分类标签：切换不同分类的网站
- 网站卡片：点击在新标签打开
- 快捷功能：防弹窗开关、清除痕迹、无痕窗、全导航

## 🔒 隐私说明

- **不收集任何用户数据**
- 所有处理都在本地完成
- 不包含任何追踪脚本（Google Analytics、百度统计等）
