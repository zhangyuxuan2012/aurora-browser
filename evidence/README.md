# 创作历程记录

本项目由本人独立构思并主导开发，使用多种 AI 编程工具作为辅助（AI 作为笔，本人为作者）。

## 演进阶段

1. **网站导航（50 站）**：最初的想法——做一个网站导航。
2. **扩展到 201 站**：逐步扩充站点数量与分类。
3. **套 Chromium 内核浏览器**：将导航封装为桌面浏览器（Electron / Chromium 内核）。
4. **增加 exe 下载功能**：让用户可从网页下载 Windows / Mac 版本。

每一阶段均有截图、历史版本与 AI 对话记录为证（见本目录及仓库 history/ 目录）。
